KOReader Plugin Runner

Load a .koplugin folder and use it on a simulated e-reader. Everything runs in this tab; your files aren't uploaded anywhere.

Tap or drag on the screen to tap and swipe. Right-click or press and hold for a long press. With the screen selected: Esc back, arrows, Enter, PgUp/PgDn, F1 menu. Full screen: Esc to leave in a browser, or the Exit button.

Load a plugin

Drop a plugin folder or a .zip here. A plugin is a folder like mygame.koplugin with main.lua inside. Drop several, or the whole plugins folder. Pick it again after editing to reload.

      What the runner can and can't do
      • It simulates KOReader's file manager screen with its UI toolkit: widgets, dialogs, menus, gestures, keys, timers and settings.
      • Plugins marked is_doc_only need an open book, so they're listed but not started.
      • Network requests and native code (ffi.C) can't run in a browser. Calls to them are skipped and noted in the console.
      • Lua runs on fengari (Lua 5.3), patched to print and round numbers the way KOReader's LuaJIT does.
      • Settings a plugin saves are kept in this browser.
